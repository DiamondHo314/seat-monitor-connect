# seat-monitor-connect
## How to use

0. Run checkSectionDetails file using `node checkSectionDetails.js`
1. Go to connect, log in
2. Open up inspect 
3. Go to the network tab in inspect 
4. Reload the page (can be any page within the website) 
5. Look for a file named `token`, single click on it 
6. Go to the `response` tab of token 
7. Copy the access token and refresh token by right clicking and choosing `Copy value`
8. Paste them into your terminal

Note that this only works for 30 minutes. You would need to manually repeat the processes after 30 minutes.
